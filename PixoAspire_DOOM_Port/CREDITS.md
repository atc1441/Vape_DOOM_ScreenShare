## Game data

The game data comes from [Freedoom](https://freedoom.github.io/) 0.13.0 (`freedoom1.wad`),
Copyright (c) 2001-2024 Contributors to the Freedoom project, under the BSD 3-clause licence
(`LICENSES/BSD-3-Clause.txt`, Freedoom's `COPYING.txt`). The repository holds none of it: the
build downloads the release and converts it. What the build derives from it:

- `DOOM.DAT` and `DOOMX.DAT`, the converted game data, which also hold the engine's strings
  and tables from doomgeneric (GPL-2.0-or-later)
- `gen/colormap.c`, the light tables, which are linked into `DOOM.BIN`
- a few sprite frame numbers from Freedoom's DEHACKED lump in `gen/info.c`

`DEMO2.LMP` is made from the test scripts, not from Freedoom.

The licence text refers to the file CREDITS for the list of Freedoom's contributors. The
build puts copies of Freedoom's `COPYING.txt` and `CREDITS.txt` into `build/packs/notices/`.
Anyone who distributes the converted data, or a `DOOM.BIN`, has to include both. The Freedoom
name and the names of its contributors must not be used to endorse or promote this project.

## Binaries

This project publishes source only. Anyone who distributes binaries built from it
(`DOOM.BIN`, `DOOMCODE.DMC`, `DOOMX.DAT`, `DOOM.DAT`) has to ship with them:

- the GPL text (`COPYING`)
- the MIT notice of the LCD values (`LICENSES/MIT.txt`), which `DOOM.BIN` contains
- Freedoom's `COPYING.txt` and `CREDITS.txt` (`build/packs/notices/`)
- the corresponding source (GPL section 3): this source tree of the same build, which
  includes the build rules and tools, together with the doomgeneric files the build fetched
  into `oracle/src/` at the pinned commit, because the converter generates parts of the
  firmware from them

Files converted from a commercial DOOM WAD (`IWAD=`) contain id Software's data and must not
be distributed.

## Tools used, not included

- [Renode](https://renode.io/) by Antmicro runs the emulated meter of the Renode tests
  (`tests/renode/`), with a board description and an LCD model written for this project.
- The reference engine of the tests (`oracle/`) is doomgeneric, fetched at the commit above
  and built from unmodified sources. Linker-wrapped hooks hash its game state and feed it
  input.
